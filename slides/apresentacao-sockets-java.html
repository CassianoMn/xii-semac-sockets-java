Parte 1 • Concorrência

Por que precisamos de Threads?

Execução Sequencial

  • Um único fluxo de controle
  • Uma tarefa bloqueia a seguinte
  • Se o servidor esperar um cliente, trava os outros

Execução Concorrente

  • Múltiplos fluxos dentro do mesmo programa
  • Compartilham a mesma memória
  • Essencial para atender vários clientes ao mesmo tempo
Parte 1 • Threads em Java

Ciclo de Vida de uma Thread

  • Nunca chame run() diretamente — sempre use start().
  • Evite métodos antigos e removidos como stop(), suspend() e resume().
Parte 1 • Código Java

Como criar Threads em Java

1. Implementando Runnable (Recomendado)

class MinhaTarefa implements Runnable {
    public void run() {
        System.out.println("Rodando na thread!");
    }
}

Thread t = new Thread(new MinhaTarefa());
t.start();

2. Forma Moderna com Lambda

Thread t = new Thread(() -> {
    System.out.println("Rodando com lambda!");
});

t.start();
t.join(); // aguarda t terminar

Vantagem: a classe continua livre para herdar outra classe (extends).

Parte 2 • Redes e Sockets

O que é um Socket?

Definição Prática

  • É a porta de comunicação entre dois processos na rede
  • Controlado pelo Sistema Operacional
  • Permite enviar e receber bytes entre Cliente e Servidor

Como encontrar o destino?

  • Endereço IP: identifica a máquina (ex: prédio)
  • Porta (0–65535): identifica o programa (ex: apartamento)
  • localhost (127.0.0.1): sua própria máquina
Parte 2 • Protocolos de Transporte

UDP vs. TCP

Característica UDP (Datagramas) TCP (Conexão)
Conexão prévia Não (envia direto) Sim (Handshake)
Confiabilidade Não garante entrega nem ordem Garante entrega e ordem dos bytes
Velocidade / Overhead Mais rápido, menor cabeçalho Mais controle, leve sobrecarga
Exemplos reais Jogos online, streaming, DNS Web (HTTP), Chat, transferência de arquivos
Classes Java DatagramSocket / DatagramPacket ServerSocket / Socket

Conectando os Pontos

Onde Threads + Sockets se encontram?

O Problema

  • accept() e readLine() são bloqueantes
  • Sem Threads, o servidor TCP só atende 1 cliente por vez

A Solução

  • A Thread principal fica só no accept()
  • Cada cliente conectado ganha sua própria Thread!
while (true) {
    Socket cliente = serverSocket.accept();
    new Thread(new ClientHandler(cliente)).start();
}
